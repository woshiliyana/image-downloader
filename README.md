# 图片预览与批量下载工具

这是一个简单的网页应用，可以帮助你批量预览和下载图片链接。

## 在线使用

访问: [https://woshiliyana.github.io/image-downloader/](https://woshiliyana.github.io/image-downloader/)

## 功能特点

- 从剪贴板读取图片链接
- 自动识别和过滤有效的图片URL
- 预览所有图片
- 选择/取消选择单张或全部图片
- 批量下载选中的图片（多张图片会自动打包为ZIP文件）
- 响应式设计，适配各种设备

## 使用方法

1. 复制图片链接到剪贴板
2. 点击"从剪贴板粘贴图片链接"按钮，或直接在文本框中粘贴链接（每行一个链接）
3. 点击"预览图片"按钮查看图片
4. 选择你想要下载的图片（点击图片或勾选复选框）
5. 点击"下载选中图片"按钮下载所选图片

## 注意事项

- 图片链接必须是完整的URL（以 http:// 或 https:// 开头）
- 每行只能包含一个图片链接
- 多张图片下载时会使用JSZip库创建ZIP文件
- 某些浏览器可能会阻止多个文件的下载，请确保允许弹出窗口

## 技术说明

该应用使用纯HTML、CSS和JavaScript构建，无需任何服务器或后端支持。它使用以下技术：

- 原生Clipboard API读取剪贴板内容
- Fetch API获取图片数据
- JSZip库（动态加载）用于创建ZIP文件
- 响应式CSS设计

## 浏览器兼容性

该应用在以下浏览器中测试通过：

- Chrome 90+
- Firefox 90+
- Safari 14+
- Edge 90+

较旧的浏览器可能不支持某些功能，特别是剪贴板API。
